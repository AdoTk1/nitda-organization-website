# NITDA Organization Website

A responsive multi-page website developed as an academic web development project based on the National Information Technology Development Agency (NITDA).

> **Disclaimer:** This is an academic project and is not the official NITDA website.

## Project Overview

The project was developed to demonstrate the design and development of a structured organizational website using HTML and CSS.

The website contains four interconnected pages:

- Home
- About Us
- Organization
- Contact Us

## Features

- Responsive multi-page design
- Semantic HTML5 structure
- Consistent navigation across pages
- Management team section
- Organizational structure and organogram
- Departments and specialized units
- Functional telephone and email links
- Responsive layouts for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Responsive Media Queries
- Git & GitHub
- GitHub Pages

## What I Learned

Through this project, I practiced translating project requirements into a functional website, organizing a multi-page project, building responsive layouts, working with Git for version control, and deploying a website using GitHub Pages.
