NITDA Organization Website

Overview
A responsive four-page informational website developed for the
National Information Technology Development Agency (NITDA) as
part of an academic web development assignment.

Pages
- Home
- About Us
- Organization
- Contact Us

Technologies
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Responsive Design

Features
- Responsive multi-page layout
- Management team section
- Organizational structure
- Specialized units and activities
- Functional navigation
- Clickable email, telephone and website links
